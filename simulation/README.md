# Simulation experiments

Code and results for the four simulation cases in the paper. The known PDE
operator is discretised exactly; the unknown mechanism is represented by a
neural network and estimated jointly with the parametric coefficients by
profiling.

## Contents

```
code/
  semipde/            the shared implementation (cases, model, training, inference)
  scripts/            exp_study.py, exp_example2.py and their sharding drivers
results/
  estimate.summary.json      estimation / prediction study
  inference.summary.json     interval and coverage study
  calibration.summary.json   noise-scale calibration
  ablation.summary.json      design / identifiability ablation
  baseline_M8/*.table.txt    estimation tables for the four cases, f != 0
  zero_f_M8/*.table.txt      the same tables with data generated by f = 0
  coverage/size_table.tex    LaTeX coverage table
figures/                     representative figures from the paper
```

## Cases

| key | equation / unknown | grid | n |
|---|---|---|---|
| `rd` | `d_t u = theta d_xx u + u(1-u)`, estimate `theta`, `f` | 1-D, `n_x = 16` | 1280 |
| `burg` | `d_t u + u u_x = nu u_xx + theta z g(x) + q(x)`, estimate `theta`, `q` | 1-D, `n_x = 16` | 1280 |
| `advz` | `d_t u + (v_0 + z v_1) d_x u = theta d_xx u + f(u)` | 1-D, `n_x = 16` | 1280 |
| `np` | Nernst–Planck, estimate two diffusivities; `f` reads `x` | 2-D, `n_x = 8` | 5120 |

Training/validation/test trajectories are 8 / 16 / 16; noise levels are 0.1 and
0.5; the estimation table uses 50 repetitions and 200 epochs, the coverage table
uses 500 repetitions and 1000 epochs (200 for `np`).

## Methods compared

1. **SemiPDE (ours)** — network mechanism plus profiled parametric coefficients.
2. **Baseline 1 (`para`)** — parametric model with `f = 0`.
3. **Baseline 2 (`nonpara`)** — nonparametric mechanism with fixed `theta`.
4. **Baseline 3 (`pinn`)** — physics-informed neural network fitting `theta`
   and `f` jointly.
5. **Baseline 4 (`cascading`)** — three-stage sieve estimator.

## Results

Estimation and prediction at `sigma = 0.1` with `f != 0` (errors `x 1e-2`;
`u_err` is the RMSE on clean held-out trajectories):

| case | n | SemiPDE `u_err` | best baseline `u_err` | SemiPDE `theta_err` | SemiPDE `f_err` |
|---|---|---|---|---|---|
| RD | 1280 | **0.925** | 5.478 | **0.388** | **18.728** |
| Burgers | 1280 | **1.528** | 4.230 | **0.488** | **25.854** |
| Adv.-Z | 1280 | **0.835** | 4.622 | **1.514** | **16.095** |
| Nernst–Planck | 5120 | **1.434** | 7.291 | **0.115** | **13.065** |

SemiPDE is the best method in all 24 cells (4 cases × 2 noise levels × 3
metrics). The `f = 0` experiment is the complementary check: there the correctly
specified parametric model is the efficiency benchmark, while SemiPDE still
beats the nonparametric and PINN baselines and recovers only a small spurious
mechanism.

Interval coverage (`sigma = 0.1`, 500 repetitions, nominal 95%):

| case | Bias (`x 1e-5`) | Std (`x 1e-4`) | C.R. 80% | C.R. 90% | C.R. 95% |
|---|---|---|---|---|---|
| RD | −83.939 | 55.411 | 0.864 | 0.928 | **0.952** |
| Burgers | −33.167 | 38.909 | 0.804 | 0.902 | **0.950** |
| Adv.-Z | −704.167 | 121.511 | 0.834 | 0.912 | **0.948** |
| NP, `theta_1` | 0.131 | 2.600 | 0.878 | 0.948 | **0.972** |
| NP, `theta_2` | 10.908 | 14.036 | 0.822 | 0.906 | **0.952** |

The two NP coordinates have a joint 95% coverage of 0.926.

The complete per-method tables are in `results/baseline_M8/` (`f != 0`) and
`results/zero_f_M8/` (`f = 0`); the coverage rows are in
`results/coverage/size_table.tex`.

## Reproducing

From this directory:

```bash
# one shard, by hand
python -I code/scripts/exp_study.py estimate --case rd \
    --repeats 50 --epochs 200 --shard 0 --shards 1 --out /tmp/rd.jsonl

# sharded, then aggregated into <out>/estimate.summary.json
bash code/scripts/run_study.sh 8 estimate --case rd --repeats 50 --epochs 200

# interval study
bash code/scripts/run_study.sh 8 inference --case burg --repeats 50 --epochs 200
```

`run_study.sh` writes one JSONL per shard under `runs/<case>/` and aggregates
them when all shards finish. Set `OUT_DIR` to keep several grids of the same
study apart.
